Filebrowser Quantum Changelog

Version 5.1.6

March 2026
  • New Map Drawing Tools: Interactive Point and Arrow annotation tools with color/label support.
  • New High-Resolution Map Printing: Dedicated print feature with custom title support and annotation capture.
  • Update Consolidated Range Slider: Unified dual date sliders into a single track for temporal map services.
  • Fix Heatmap Inspection: Resolved box selection context bugs and added auto-drill for single-folder clusters.
  • Fix Popup Accessibility: Added scrollbars and restricted max-height for feature detail popups.

Version 5.0.9

March 2026
  • New System Debug Page: Added a comprehensive Debug configuration page for administrators.
  • New Maintenance Mode: Admins can now put the site into 'TESTING' state, restricting access to normal users.
  • New Debug Copy Button: Instantly copy raw configuration state to clipboard securely.
  • Fix Map Overlays: "Show ALL" map view now correctly aggregates your entire user root instead of being locked to the current folder view.
  • Fix Portainer Scopes: Fixed a path resolution bug causing user scopes to drop connection in non-Windows configurations.
  • Update Dropdown Menus: The top-right Folder Options menu now accurately detects clicks outside of the menu window to close cleanly.
